# Roblox Helper Discord Bot
 
Discord bot powered by the Grok (xAI) API. Works only in one channel and only answers Roblox Studio questions.
 
## Setup
1. Install Node.js 18+
2. `npm install`
3. Copy `.env.example` to `.env` and fill in your keys
4. `npm start`
## Discord Developer Portal
- Create app -> Bot -> copy token
- Enable **Message Content Intent** under Bot -> Privileged Gateway Intents
- Invite with scopes `bot` and permissions: View Channel, Send Messages, Embed Links, Read Message History
